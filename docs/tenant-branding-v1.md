# Tenant branding v1

Verified customer portal and Companion headers can display the current MSP's Milepost logo. Selection uses only the existing verified binding's provider_tenant_slug. Page rendering performs no branding HTTP. Anonymous/error/unbound/house contexts and absent configuration keep their original artwork.

The fixed /portal/tenant-brand-logo.php image route independently runs existing authentication, current binding, access and revocation checks, closes the session, and makes one fresh bounded request to the fixed Milepost service. The optional surface enum safeharbor|companion selects only a fallback picture. It never selects a provider, tenant, account or revision. A valid existing Companion pair takes precedence. Product names, home links, titles, favicons, mascot/avatar and intrinsic logo geometry are preserved. Personal user branding is unchanged.

Merge app/config/tenant_branding.sample.php's empty tenant_branding.service_secret during the coordinated release. It matches only Milepost tenant_branding.read_keys.safeharbor: exactly 64 lowercase hex characters used as literal ASCII HMAC key bytes, never hex-decoded. Keep actual keys out of Git.

POST https://support.8westit.com/api/svc/tenant-branding.php accepts exactly integer version=1 and server-verified provider_tenant_slug, at most 512 bytes. Headers X-8W-Brand-App/Timestamp/Nonce/Signature use safeharbor, 10 decimal timestamp digits, fresh 32 lowercase hex nonce and HMAC. Request signature joins 8west-msp-brand-v1, request, safeharbor, POST, /api/svc/tenant-branding.php, timestamp, nonce and SHA256(raw body), with newlines and no trailing newline. Response signature in X-8W-Brand-Signature joins that domain, response, safeharbor, HTTP status, request timestamp, nonce and raw-body hash.

The signed response must match the selected provider and strict version/provider_tenant_slug/revision/logo schema. Actual PNG/JPEG/WebP bytes, canonical base64, size, hash, MIME and dimensions are verified. Empty/reset, errors, stale or mismatched signatures, oversized response and timeout retain the original fixed default. TLS is verified; redirects are disabled; connect/total bounds are 1s/2s and response cap is 2,800,000 bytes. Media is private/no-store/nosniff and no persistent provider/logo cache exists. Each client switch gets a fresh independently verified media request.

Run php app/tests/tenant_branding_test.php for injected protocol fixtures and php app/tests/portal_companion_branding_test.php for rendered default/pair/context/config boundaries. Fixtures perform no external service request. Normal source/docs/CI review and current release ownership precede integration. MAIN retains key configuration, matching producers/consumers, runtime verification and customer acceptance. Source tests are not deployed acceptance.
